# Instrumentos de validación con motociclistas

**Estado:** preparado para aplicación; no contiene resultados ni participantes.

Este archivo centraliza el protocolo que se incorporó como Apéndice A del Word de tesis. No debe usarse para afirmar que se hicieron encuestas o pruebas hasta que se almacene evidencia real con fecha y consentimiento.

## Objetivo

Evaluar comprensión del alcance de MotoSafe, interpretación de cobertura y procedencia, navegación básica y problemas de interfaz en usuarios motociclistas.

## Participantes

- Mayores de 18 años.
- Conducen motocicleta al menos una vez por semana en CABA o GBA.
- Muestreo intencional con diversidad de zona y frecuencia de uso.
- No registrar nombres, domicilios, recorridos personales ni credenciales.

## Consentimiento breve

> La participación es voluntaria. Se evalúa un prototipo académico, no su capacidad de conducción. Las respuestas se registran sin datos identificatorios y se analizarán de manera agregada. Puede abandonar la actividad en cualquier momento.

## Tareas observables

1. Buscar una zona o avenida conocida y activar una capa.
2. Comparar dos rutas y explicar la cobertura que muestra el sistema.
3. Filtrar la prensa por “Motos” y abrir una noticia.
4. Explicar la diferencia entre “sin datos” y un nivel bajo de exposición.

Registrar para cada tarea: completada / con ayuda / no completada; tiempo aproximado; error observado; comentario literal relevante.

## Cuestionario

1. Frecuencia de uso de motocicleta.
2. Zona habitual de circulación.
3. Fuentes que usa actualmente para decidir recorridos.
4. La procedencia y antigüedad de una capa ayudan a interpretarla (1–5).
5. Comprendo que el modelo estima gravedad condicionada a un siniestro y no predice accidentes futuros (1–5 + explicación).
6. Puedo distinguir “sin datos” de un nivel bajo de exposición (1–5).
7. El mapa, filtros y textos son legibles y navegables (1–5).
8. Qué generó confusión (abierta).
9. Qué funcionalidad modificaría o agregaría (abierta).

## Análisis y uso permitido

- Presentar conteos descriptivos y citas anonimizadas.
- Separar hallazgos de interfaz, interpretación del riesgo y propuestas de producto.
- No generalizar a toda la población motociclista con una muestra de conveniencia.
- Documentar fecha, modalidad, versión del sistema, consentimiento y cambios realizados a partir de cada sesión.
- Incorporar resultados al Capítulo 7 solamente cuando exista evidencia completa.
